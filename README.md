 Sweet Crumbs Bakery Website

 Project Description

Sweet Crumbs Bakery is a responsive bakery website developed as part of a Web Development Portfolio of Evidence (POE). The website provides customers with information about the bakery, its products, locations and ordering process.

The website uses HTML5, CSS3 and JavaScript to create a simple, user-friendly experience. Customers can browse cakes, cupcakes, pastries and seasonal specials, use product search and filtering features, add products to a shopping cart, review their order and complete an enquiry form.

 Project Objectives

The main objectives of the project are to:

- Create a multi-page bakery website.
- Use HTML5 to structure the website content.
- Apply CSS3 to style the pages consistently.
- Make the website responsive on desktop, tablet and mobile devices.
- Use JavaScript to add interactive features.
- Provide product information and pricing.
- Allow customers to review shopping cart items and quantities.
- Provide checkout, enquiry and contact forms.
- Add basic search engine optimisation (SEO).
- Document the project and its development changes.

 Website Pages

1. Home Page

The Home page introduces Sweet Crumbs Bakery and provides an overview of the bakery and its products.

2. About Us Page

The About Us page provides information about the bakery, including:

- Our Mission
- Our Vision
- Our Team

The page also includes an image representing the bakery.

3. Products Page

The Products page displays the bakery's products, descriptions and prices.

Cakes
- Birthday Cake
- Wedding Cake
- Custom Cake

Cupcakes
- Vanilla Cupcakes
- Chocolate Cupcakes
- Red Velvet Cupcakes

Pastries
- Croissants
- Danish Pastries
- Chocolate Pastries

Seasonal Specials
- Seasonal Special

The page includes product search, category filtering, price sorting, product images and Add to Cart buttons.

A shopping cart section allows customers to review products and quantities, remove items and view order totals.

 4. Cart Page

The Cart page provides a place for customers to review selected products, check quantities and prices, remove items and review the cart total.

 5. Checkout Page

The Checkout page displays the order summary and provides customer fields for checkout, including contact details, delivery address and delivery method.

Required fields are validated by the browser before the form can be submitted.

6. Enquiry Page

The Enquiry page allows customers to enquire about products and custom orders.

The form includes:

- Full Name
- Email Address
- Phone Number
- Product Interested In
- Quantity
- Event Type
- Event Date
- Preferred Flavour
- Special Requirements

 7. Contact Page

The Contact page provides bakery contact information for the Johannesburg and Pretoria branches, including addresses, phone numbers, email address, opening hours and Google Maps.

Customers can also use the contact form to send a message.

Technologies and Tools Used

- HTML5:Structures the website pages and forms.
- CSS3:Styles the pages, navigation, product cards and layouts.
- JavaScript: Supports interactive features such as the shopping cart, product search, filtering, sorting, image lightbox and form behaviour.
- Visual Studio Code: Used to create and edit the website files.
- Google Chrome: Used to open and test the website.
- Google Maps: Used to display the bakery branch locations.
- Git and GitHub: Intended for version control and project submission.

 Design

The website uses a bakery-inspired design with soft colours, readable typography, styled navigation and product cards.

The pages are organised to help customers find products, view prices, navigate between sections and contact the bakery.

The existing Home and About Us designs were retained while other pages and features were improved.

 Responsive Design

CSS media queries and responsive layout rules are used to adapt the website to different screen sizes, including:

- Desktop computers
- Tablets
- Mobile devices

Images and page layouts are styled to adjust to smaller screens.

JavaScript Functionality

The JavaScript functionality includes:

- Adding products to the shopping cart.
- Saving cart items in browser local storage.
- Displaying saved cart items.
- Updating product quantities and totals.
- Removing products from the cart.
- Searching for products.
- Filtering products by category.
- Sorting products by price.
- Opening and closing the image lightbox.
- Checking required form fields through browser validation.
- Supporting checkout and enquiry navigation.

Cart information saved in local storage can remain available in the same browser between page visits.

Note: The current checkout and form navigation should not be treated as a completed online payment or order-processing system. A live ordering system would require an appropriate backend or connected service.

 Search Engine Optimisation (SEO)

Basic SEO improvements were added to the website.

These include:

- Page titles relevant to each page.
- Meta descriptions describing page content.
- Character encoding using UTF-8.
- Viewport metadata for responsive display.
- A `robots.txt` file.
- A `sitemap.xml` file listing the main website pages.

The website is currently stored locally on the computer. The sitemap still contains placeholder website addresses and must be updated with the actual public URLs after deployment.

The website has not yet been confirmed as published or indexed by search engines.

 How to Run the Website

1. Open the Sweet Crumbs Bakery project folder.
2. Open `index.html` in Google Chrome, or use the available local preview feature in Visual Studio Code.
3. Use the navigation menu to visit the website pages.
4. Test the product search, filters, shopping cart, checkout and forms.
5. Check the layout on different screen sizes.

Some features, such as public search engine crawling, require the website to be published online.
